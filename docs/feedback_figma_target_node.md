FigmaのURLに `node-id=` が含まれて作業依頼された場合は、そのノードを直接編集する。別の場所に複製や新規フレームを作って並べて提示しない。

**Why:** ユーザーは指定ノードの置き換え案を求めている。横に並べた複製は「そこに作ってくれと言っているのに分からないのか」と明確に拒否された。

**How to apply:** node-id付きURLを受け取ったら、use_figmaでそのノードのツリーを書き換える（必要なら子ノードを差し替える）。既存ノードのクローンをページに追加するパターンは使わない。バックアップが必要か事前に確認してもよいが、原則はin-placeで編集。

**指定がPageノードの場合（=置き場所指定）:** node-idが空のPage（例「トップ」node 123:456）を渡されたら、その**指定Pageの上に**成果物を作る。勝手に別の新規Pageを切ってそこに置かない。複数案を作る依頼でも、フレームを指定Page上に横並びで置く。新規Pageに作って「3案できました」と出したら「なんでトップのページにない？」と拒否された。
